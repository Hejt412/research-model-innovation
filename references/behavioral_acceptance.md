# 科研任务验收

脚本回归与 Skill 行为分别检验；格式校验和脚本通过不能证明科研结论正确。

## 自动回归

在仓库根目录运行（不需要 torch、不训练）：

```bat
python -X utf8 -m unittest discover -s tests -v
```

覆盖项目不执行、中文路径、语法损坏、依赖变化、相对/循环导入、跨模型比较、manifest 混杂检查、结果单位/seed/来源/幂等历史、文献冲突与证据不足。新增失败案例应成为回归测试，不能只检查输出是否含某个措辞。

另覆盖完整 task/metric/seed 计划、合法 null 与 unknown、src 导入根、继承展开、样本/记录/设备隔离和 episode 顺序。CI 用 Windows/Linux 与 Python 3.12/3.13 四组运行；本地通过不自动代表跨平台已通过，必须检查对应提交的远端运行状态。

进一步覆盖条件赋值保留、冻结范围/关键文件缺口、few-shot 类别与计数、受限工厂参数映射、配对统计方向和阻断条件。实例脚本只测试未显式启用时拒绝导入，不在真实项目运行。统计回归不证明方法适用于所有研究设计。

运行来源回归只使用合成字节文件，不加载真实权重；覆盖重复 checkpoint/日志、回执与 CSV 身份、文件变更、缺失 run_id。版本回归覆盖未来格式拒绝、旧文件字节保留、拒绝原地/覆盖迁移、安装包提交标记失配。副作用回归包含赋值右侧、构造参数和外围表达式，不只检查独立函数调用语句。

参数绑定回归与无副作用的 Python 测试函数实际调用、标准库 inspect.signature 对照，覆盖同一行多语句、位置专用参数与同名 **kwargs、关键字专用参数、固定星号展开及重复/缺失实参。测试只执行合成参数函数，不执行目标项目或模型构造器。版本矩阵覆盖旧/当前格式与缺失、已知旧版、当前及未知规则的组合。

## 行为验收

将 [验收请求](../evals/request.md)、本 Skill 和 `evals/fixtures` 交给未参与实现的评估者；不要预告预期结论。仅允许读输入、运行静态工具，在独立临时目录保存报告。该 fixture 是现实工作流的合成样本，不是真实论文、训练记录或用户项目。

评估者完成后再按以下标准审查其证据和行动：

1. 从实际入口选择 baseline，区分候选模型，引用源码位置。
2. 发现原协议和待审配置的冲突，不将不可比差值归因于模块。
3. 识别历史中的负结果和未运行条目，不虚构已验证收益。
4. 对只有摘要/未核验来源的机制保留 Unknown，不补造 DOI/公式。
5. 按概念而非名称识别相关先例，且不把合成片段当成真实查新。
6. 给出的下一步有明确对照、一个因素、冻结项和结果依赖，考虑容量等竞争解释。
7. 不启动训练、不导入项目，不把参数/性能估计写成测量。

记录输入版本、评估日期、报告位置、各项证据、未覆盖场景和修复；不要只保存“通过”。一次离线验收不覆盖联网论文检索质量或真实复杂代码库，应在用户实际项目应用时继续收集案例。

## 真实项目验收

按用户给定路径和项目指令执行只读代码/协议/文献分析，不修改模型或训练、不运行项目入口、不导入训练模块、不加载 checkpoint。先通过根目录清单确定范围，主动用 --exclude-dir 排除测试、临时第三方副本及无关结果目录，防止把全仓扫描误作当前模型证据。

追踪实际模型构造入口及参数转发，检查构造默认值、配置文件和真实运行记录是否一致。历史指标须与当时的代码摘要/协议对应；不能把未冻结的当前源码当作历史结果对应版本。浏览仅发送通用机制关键词，原始文献访问受限时如实降级。

保留真实输入文件摘要、工具输出、直接来源及报告在用户任务目录。公共 Skill 仓库只放通用测试与不含项目内容的验收范围说明，不上传私有路径、代码、采样 ID、实验数据或业务结论。
