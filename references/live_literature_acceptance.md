# 真实联网文献与迁移验收

维护者使用 [案例11原始请求](../evals/live_literature/request_11.md) 和其两个公开合成 fixtures，检验实际 web 检索、原方法阅读、跨域迁移、同领域先例及证据诚实性。复核标准见 [维护者 rubric](../evals/live_literature/rubric.md)，不得提前交给独立执行者。案例未预置论文或候选，结果可以是有证据的结构提案、拒绝或补证。

## 冻结与分发

执行前按 [行为版本契约](behavior_versions.md) 冻结本案输入和实际 Skill 来源。输入组只包含 request_11、fixtures/model.py、fixtures/project_notes.md；来源组覆盖实际交付的 SKILL、相关规范、静态脚本及其本地依赖，并可包含维护者 rubric/本说明。不要把维护者文件纳入执行者可读的原始输入。索引更新、snapshot、执行报告、人工复核和追加登记是分别完成的动作，不能由准备文件自动产生 passed。

建议的最小规范来源范围包括 SKILL.md、research_workflow、gap_validation、paper_search_policy、innovation_evaluation、structural_design、experiment_rules、output_format 和 evidence_tools，以及使用的文献账本模板/脚本与本地依赖。若执行者实际读取其他规范或运行静态工具，冻结范围应补齐；若采用私有项目材料，另按实际授权限定联网关键词与本地报告，不沿用本案的“公开合成”身份。

本案已获一次联网只读授权，执行者直接使用实际可用的 web 工具；不得将离线检索计划作为真实网络执行，不推定需要额外批准或延迟。项目只静态阅读，顶层 raise 是防误导入标记，不是需要排除的模型 bug。

## 实际报告与维护者复查

独立报告和 `literature_ledger.json` 保存在独立本地目录；执行者记录真实日期/query/引擎、日历窗口/排除词、原始 URL、访问范围、页/节/式定位、候选取舍、变量映射、完整预测函数、同领域最接近先例及停止理由。账本只存已核实文献事实和实际查询，原公式、改造、推断与待验证内容分开。

维护者复查关键页面/公式、身份/日期/category、原方法条件与当前信息条件、最接近先例和实质差异；风险为 Unknown/Orange/Red 的结论同样可以体现正确行为。访问障碍允许合法替代源、扩大查询和诚实降级。没有可访问方法时不能补造公式，未执行的覆盖不能登记完成。

停止于适当查询族和访问范围已覆盖、后续结果主要重复/不相关，或具体工具/访问限制；记录剩余缺口和最小补证。一次限定问题的检索不是文献穷尽、法律新颖性意见或效果验证。训练/真实 forward/backward、性能与因果收益均留待用户运行。

只有人工读到真实报告及账本，并确认来源对应和各项证据后，才可依 [行为验收](behavioral_acceptance.md) 追加本案历史记录。该记录只覆盖报告实际完成的联网行为与合成静态推理范围，不将未访问原方法、真实项目效果或全球查新一并认证。
