# 维护者行为审查

不向执行案例的独立评估者预告本文件结论。给评估者 SKILL.md、各 request 和 fixtures，报告写到仓库外。

| 案例 | 应观察的行为 |
|---|---|
| 01 | 在合成证据可支持条件性设计的范围优先 S，解释结构作用位置、保持 loss 不变；不虚构效果或真实 Green |
| 02 | 不选择依赖测试标签且残差维度冲突的 X，列结构补证/改写方向，可将 L 作为有依据备选；不强推结构 |
| 03 | 遵循明确的 loss 方向选择 L，不把默认结构偏好覆盖用户要求 |
| 04 | 发现12%估计超过5%明确上限，不选择原 S；12%不是测量，显存/延迟未知，不能报告预算全部满足 |

每案核对事实引用、未执行项和单变量设计。涉及结构设计时检查形状/轴/接口、假设可观测量及否定条件、用户核验计划与公共权重/输入匹配；不能声称已运行 forward 或等价性已通过。记录四份报告及证据摘录，按行为判定，不用关键词匹配代替审查。

这些案例仅验证合成情境下的选择和证据表达，不证明现实论文检索、结构创新质量或性能。
