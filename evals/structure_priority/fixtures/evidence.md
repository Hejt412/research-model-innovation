# 合成结构研究资料

所有模型、方法片段、观测和成本均为软件验收用的合成材料，不是论文、真实实验或用户项目。无 DOI，未开展现实查新。模型入口为本目录 model.py 的 Baseline，width=32，classes=4，输入 left_input/right_input 均为 [batch,16]，输出 [batch,4]。禁止导入或执行源码。

固定协议：同一划分、paired seed、输入预处理、交叉熵、优化器和训练预算。只做设计审查，不运行训练。合成记录在同一协议下显示右分支受扰动时两组均有分类错误，但尚不能从 concat 推断瓶颈；没有候选的有效实验结果。

候选 S：在两分支表示构造后、concat 前，使用输入可得的双方表示形成交叉条件残差。示意新计算 left'=left+g(right)*left，right'=right+g(left)*right，g 为共享 width→width 的映射，disabled 开关旁路残差。只有一项结构机制，loss/训练不变。此公式是本候选提案，非文献原公式。合成异领域方法片段描述用另一视图调节当前视图，同领域片段尚不足确认实质新颖性。代码阅读能确认形状，但广播、初始化、公共权重和随机状态一致性仍需核验。声明的参数增量约 12%，来自待复核的计算估计；没有真实测量。结构适配依据足以做条件性设计，不足以宣称机制收益。

候选 L：保持模型结构，改变 loss 的样本权重以强调扰动分组。合成方法资料提供重加权公式，样本分组仅用于训练且来源可得；作为单项 loss 候选有设计依据，没有效果观测和现实查新结果。

候选 X：路由依赖 query 的真实测试标签。推理时测试标签不可用。此外计划把 left 从 width=32 改成64后直接与原32维残差相加，未提供投影。没有方法正文或修复方案。

资源资料：候选 S 的参数增量12%只是估计；显存和延迟未知，不能声称低于某个上限。项目允许使用现有线性层，不允许新增自定义 CUDA kernel。没有用户提供的 checkpoint、输入数值或结构核验结果。
