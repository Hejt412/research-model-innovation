# 公开合成项目说明

这是为 Skill 行为验收公开制作的最小合成资料，不是用户私有项目、真实设备数据或实际训练记录。`model.py` 只能静态阅读，顶层异常用于阻止误导入；本目录没有可执行的数据生成、训练、评估或模型核验入口。

## 应用与接口

应用语境设为多传感器设备状态识别。每条独立记录有两路无量纲的合成摘要 `x, y ∈ R^16`，可类比两个传感器各自的观测摘要，但它们没有对应真实物理测量。输入分别为 `[B,16]`，两路中间表示分别为 `[B,32]`，输出为四类 logits `[B,4]`；batch 轴表示互相独立的记录。本任务没有时间轴、跨记录状态、support set、缓存或因果前缀要求。

训练阶段可用两路输入和该记录的类别标签；推理阶段只能使用当前记录的 `x/y`。设备身份、工况标签、未来记录、测试标签和外部检索记忆均未提供。源方法若依赖这些信息，需说明其迁移条件是否成立。

## 未执行的合成目标定义

以下是任务的数学定义和拟议采样规则，不是已经生成的数据集或观测结果。对 `i ∈ {0,1}`，`x_i/y_i` 各自独立、等概率地从 `[-1,-0.25]` 或 `[0.25,1]` 均匀采样，允许这四个坐标的所有符号组合；其余坐标作为独立的 `[-1,1]` 均匀噪声。所有记录按相同规则独立采样。

令 `q_i = 1[x_i y_i > 0]`，类别为 `c = 2q_0 + q_1 ∈ {0,1,2,3}`。四类只表示两对观测分别同号或异号的组合，不代表已经识别的物理故障。这一目标明确含有成对条件关系，单路符号的绝对取值不能独立决定类别。

此定义可以用于静态数学讨论或规划后续合成诊断。它不能证明真实设备标签遵循此规则，不能证明 baseline 在实际数据上的误差来自交互能力，也不能把计划中的采样分布当成已核验数据事实。
